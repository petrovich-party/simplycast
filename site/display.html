05Что важно знать

Ограничения версии 1.0.

Лучше сказать заранее.

Режим «Расширить» работает без второго монитора?

Нет. В комплекте пока нет драйвера виртуального монитора: расширенный экран доступен, когда Windows видит второй дисплей — физический или созданный сторонним драйвером. Зеркало работает всегда.

Слышен ли звонок на компьютере?

Нет. Звонки и SMS можно принимать и отправлять с ПК, но Android не отдаёт звук разговора, поэтому он идёт через телефон.

Какие порты открывать в брандмауэре?

TCP 7777 для сессии и UDP 7778 для автопоиска компьютеров. Порты 7779–7781 нужны дополнительным функциям.

Работает ли браузерный клиент?

Встроенный клиент для браузера работает по http и рассчитан только на домашнюю сеть, поэтому по умолчанию выключен.

Windows предупреждает при запуске. Это нормально?

Приложение пока без платной цифровой подписи, поэтому SmartScreen может показать предупреждение. Нажмите «Подробнее → Выполнить в любом случае».
